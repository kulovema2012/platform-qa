# Content and community

Covers blogs, forums, social features, courses, media libraries and member communities.

| Role | Feature | Why it matters |
|---|---|---|
| Member | Create, edit and delete own posts with drafts | Basic authoring |
| Member | Rich text or media with safe rendering | Formatting without script injection |
| Member | Follow, subscribe or save content | Reasons to come back |
| Member | Notifications for replies and mentions, with controls | Engagement without spam |
| Member | Search content and people | Finding things past the first page |
| Member | Report content or users | Community safety |
| Member | Block or mute other users | Personal safety |
| Member | Privacy settings for profile and posts | Control over visibility |
| Moderator | Moderation queue with reasons and actions | Reports need handling |
| Moderator | Hide, lock, move or remove content with a record | Consistent moderation |
| Moderator | Warn, suspend or ban users | Repeat offenders |
| Moderator | Spam detection and new-account limits | Spam floods otherwise |
| Admin | Categories, tags and pinned content | Structure as content grows |
| Admin | Community rules and terms acceptance | Basis for moderation decisions |
| Admin | Analytics: active members, top content | Understanding the community |
| Admin | Content export and backups | Ownership of the community's work |
| Creator | Scheduling and version history | Planned publishing; undo mistakes |
| Creator | Access control for paid or member-only content | Monetization |
| System | Takedown and copyright request process | Legal duties in many regions |

This catalogue is a starting point. Check the app's own docs and decisions before calling anything missing.
