# Features nearly every app needs

Check these for every app, whatever its industry. A missing item is a suggestion, not a defect, unless the app's docs promise it.

| Role | Feature | Why it matters |
|---|---|---|
| User | Sign-up or invite acceptance with clear errors | People who cannot get in never become users |
| User | Password reset or account recovery | Locked-out users become support tickets or leave |
| User | Sign out everywhere; see active sessions | Lost or shared devices stay signed in otherwise |
| User | Profile and email change with confirmation | Typos and job changes are common |
| User | Delete account and export own data | Required by privacy laws in many regions; builds trust |
| User | Notification preferences | Unwanted mail gets marked as spam |
| User | Helpful empty states and error pages (404, 500, offline) | First impressions and recovery from mistakes |
| User | Accessible basics: keyboard use, labels, contrast, works at phone width | Excludes users and can breach accessibility law |
| User | Help or contact route | Users stuck with no way to ask leave |
| Admin | User management: invite, change role, disable, remove | Teams change; access must follow |
| Admin | Audit log of sensitive actions | Answering "who changed this?" after a mistake or dispute |
| Admin | Search and filter on main records | Lists stop being usable past a few hundred items |
| Admin | Export of business data | Accounting, backups, moving to another tool |
| Admin | Basic usage or health overview | Problems otherwise found by users first |
| Owner | Ownership transfer; at least one owner always | Business continuity when people leave |
| Owner | Billing view and invoices (paid apps) | Customers need receipts for accounting |
| System | Backups and restore procedure | Data loss is usually unrecoverable without them |
| System | Rate limiting on sign-in and expensive actions | Abuse and runaway costs |
| System | Structured error logging and alerts | Silent failures go unnoticed |
| System | Terms, privacy policy and cookie notice where required | Legal exposure |

This catalogue is a starting point. Check the app's own docs and decisions before calling anything missing.
