# Finance and spending

Covers expense tracking, bills and invoices, budgets, approvals and bookkeeping-style apps.

| Role | Feature | Why it matters |
|---|---|---|
| Member | Capture a bill or receipt (upload, photo, email forward) | Lost receipts mean unclaimable spend |
| Member | See the status of what they submitted | Uncertainty causes duplicate submissions |
| Member | Edit or withdraw before approval | Mistakes are common at entry |
| Member | Duplicate warning for the same bill | Double payment is a direct loss |
| Approver | Approve or reject with a reason | Accountability and feedback |
| Approver | Approval limits by amount or category | Large spend needs higher sign-off |
| Admin | Void or reverse a posted record instead of deleting it | Financial history must stay traceable |
| Admin | Categories, cost centres, projects and tags | Reporting by where money goes |
| Admin | Budgets with alerts when close to or over | Overspend found too late otherwise |
| Admin | Recurring bills and subscriptions | Forgotten renewals |
| Admin | Multi-currency with the rate used recorded | Accurate totals and audit |
| Admin | Tax fields (VAT, withholding) per record | Correct filings |
| Admin | Reconciliation against bank or card statements | Catches missing or wrong records |
| Admin | Export to accounting software or CSV | Accountants work in their own tools |
| Admin | Period close / lock past periods | Stops changes to filed numbers |
| Admin | Audit trail on every money change | Required for audits and disputes |
| Admin | Unknown amounts stay unknown, never zero | Zero hides missing data in totals |
| Owner | Spending reports by period, category, vendor and person | Decisions and tax preparation |
| Owner | Role separation: who enters, who approves, who pays | Basic fraud control |
| System | Document retention and deletion rules | Legal retention periods vary by country |

This catalogue is a starting point. Check the app's own docs and decisions before calling anything missing.
